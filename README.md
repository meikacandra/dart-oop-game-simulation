# Simulasi Karakter Game (Dart OOP)

Proyek simulasi pertarungan sederhana menggunakan bahasa pemrograman Dart untuk mempraktikkan konsep dasar Object-Oriented Programming (OOP).

## Konsep OOP yang Diterapkan
- **Class & Object**: Pembuatan entitas karakter game (`Karakter` dan `Healer`).
- **Encapsulation**: Penggunaan atribut privat (`_healthPoint`) dan getter `sisaDarah` tanpa setter.
- **Inheritance**: Class `Healer` mewarisi class `Karakter` dengan keyword `extends`.
- **Constructor & `super`**: Inisialisasi properti dengan named parameter `required` dan delegasi ke constructor induk via `super`.

## Cara Menjalankan
Jalankan file `main.dart` menggunakan perintah:
```bash
dart run main.dart
```
